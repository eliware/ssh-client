# Examples

Use [example.mjs](example.mjs) as a starting point for SSH commands.
Use [integration.mjs](integration.mjs) to check a live SSH connection.

Set `SSH_PRIVATE_KEY_PATH` and `SSH_KNOWN_HOSTS` before you run the example.
Run `node examples/example.mjs` from the repository root.
The command example imports the public API from `src/public-api.mjs`.
Set the `SSH_CLIENT_INTEGRATION` variables before you run the integration example.
